# 🍅 A História do nosso tomatinho

## Sobre o projeto

O Tomato Roots é uma aplicação web criada para apresentar
informações sobre a produção de tomatinho em estufa de forma
simples, acessível e transparente.

O projeto utiliza a ideia de rastreabilidade digital para
aproximar o consumidor da história do produto e das práticas
realizadas durante sua produção.

## 🎯 Problema

Informações sobre a origem e o processo de produção de alimentos
muitas vezes ficam restritas aos registros internos do produtor
ou são apresentadas apenas por meio de informações impressas.

Isso dificulta o acesso do consumidor à história do produto.

## 💡 Solução

O projeto utiliza um QR Code  e link para direcionar o consumidor a uma
página digital com informações sobre o produto e sua produção.

A proposta é tornar a rastreabilidade mais acessível, utilizando
uma interface simples e de fácil consulta pelo celular.

## 🍅 Produto

O projeto foi desenvolvido inicialmente para o acompanhamento do
tomatinho produzido em estufa.

As mudas utilizadas na produção são adquiridas pelo grupo e
posteriormente cultivadas na propriedade.

## 📋 Informações apresentadas

- Informações sobre o produto
- Origem da produção
- Contexto do cultivo
- Informações sobre o manejo
- História da produção
- Rastreabilidade por QR Code
- Canal de contato

## 🌱 Contexto

O projeto foi desenvolvido a partir de uma necessidade real
relacionada à rastreabilidade da produção agroecológica.

A proposta é utilizar tecnologia para aproximar o consumidor
da produção e facilitar o acesso às informações do alimento.
